# Teaboom — карточка товара

Тестовое задание: карточка товара «Ананасовый улун».

## Что реализовано

- адаптивная верстка для 1440 px, 768 px и 375 px
- выбор фасовки
- изменение артикула и цены
- активное состояние выбранной фасовки
- hover-эффект кнопки «В корзину»

## Запуск

Открыть файл `index.html` в браузере.
